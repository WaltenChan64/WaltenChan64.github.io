Overview

What I worked on

Saleblazers is a multiplayer survival shop-building game on Steam, developed by Airstrafe Interactive. During my internship I worked across several areas — runtime gameplay systems, editor tooling, performance, and networking — shipping features that are still live in the game today.

Below is a breakdown of each major thing I built, including the technical decisions and tradeoffs involved.

Feature 01

NPC Conversation Generation System

TODO get screenie

I built a fully modular NPC conversation generation system that assembles ambient dialogue dynamically at runtime. Rather than hard-coding NPC conversations, the system draws from designer-authored dialogue fragments and combines them contextually — making the world feel more alive without requiring constant manual scripting.

A key goal was making the system accessible to designers without needing to touch code. I wrote a companion technical document explaining the flow of the conversation system so designers could author and iterate on dialogue independently.

💡 Designers could add, test, and adjust dialogue without filing a code request or waiting for a programmer — cutting iteration time significantly.

Feature 02

World Spawner & Patrol Route Visualizer

TODO get screenie

I collaborated with designers to build a custom Unity editor extension that visualizes 2,000+ world spawners, NPC patrol routes, and loading zones — all in a single, glanceable view. Each spawner shows its type, state, and configuration directly in the editor, and designers can edit them on the fly without hunting through scene hierarchies.

At 2,000+ spawners, the previous workflow of cross-referencing spreadsheets and scene files didn't scale. The tool replaced it entirely.

💡 The entire world — every spawner, patrol route, and loading zone — now auditable and editable in one view.

Feature 03

Networked Multiplayer Sleep System

TODO get screenie

I designed and implemented a fully networked sleep system for Saleblazers' multiplayer sessions. The core challenge: when multiple players want to sleep, the game needs to agree on how many hours are available — determined by whichever player has the fewest hours they can sleep.

This required syncing all connected players in real time, electing a "sleep leader" who gets the final say on the sleep duration, and handling the case where that leader disconnects mid-decision.

The system also had to behave correctly across two fundamentally different network topologies: P2P sessions (where the host is always the sleep leader) and dedicated servers (where the leader role needs to migrate if the current leader leaves).

💡 The trickiest part was leader migration on dedicated servers — unlike P2P where the host is always present, a dedicated server session needed a clean handoff when the leader disconnected mid-vote.

Feature 04

Terrain Loading & Audio Rework

TODO get screenie

I reworked the terrain loading and camera system to reduce visual popping — the jarring moment when terrain chunks load in abruptly as the player moves through the world. The changes made transitions smoother and less noticeable to players.

As part of the same pass, I precomputed the ambient "grassy" sounds that should play from each location in the world, rather than calculating them dynamically. This reduced per-frame audio overhead and improved consistency across the soundscape.

💡 Performance work that players feel but never notice — exactly how it should be.

Feature 05

Voice Communication & Bug Fixes

I wrote the networked voice communication feature, allowing players to talk to each other in-game sessions. I also spent significant time addressing player-reported bugs — working through the issue tracker, reproducing problems, and shipping fixes that improved overall gameplay stability and responsiveness.

Bug fixing on a live game is different from fixing bugs in a project environment — you're working in a large unfamiliar codebase, under time pressure, and changes affect real players immediately. It was some of the most useful experience I got during the internship.
